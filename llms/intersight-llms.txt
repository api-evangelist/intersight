# Cisco Intersight

> Cisco Intersight is Cisco's SaaS operations platform for UCS servers, HyperFlex clusters, Nexus fabrics,
> third-party storage and virtualization — provisioning, firmware lifecycle, workload optimization, telemetry
> and Kubernetes service delivery. The full REST contract is published anonymously as OpenAPI 3.0.2:
> 3,963 operations across 2,448 paths and 5,612 schemas.

## Authentication

- **HTTP Signature** (draft-cavage-http-signatures) with an API key id and secret — the programmatic path. Sign `(request-target)`, `(created)`, `Host`, `Date`, `Digest`.
- **OAuth 2.0** — authorization code (`/iam/app-authorize`, `/iam/token`) with 54 `ROLE.*` scopes, or client credentials with fine-grained `CREATE.*`/`READ.*`/`UPDATE.*`/`DELETE.*` scopes. 3,317 scopes in total.
- **Cookie** (`X-Starship-Token`) — browser SSO sessions only, not for clients.

## Calling conventions

- **Query**: OData-style — `$filter`, `$orderby`, `$select`, `$expand`, `$apply` (groupby/aggregate), `$top`, `$skip`, `$count`, `$inlinecount`, plus `at` and `tags`.
- **Pagination**: offset, `$top` (default 100) and `$skip`.
- **Identifiers**: every resource carries a 24-character `Moid`, plus `ObjectType` and `ClassId`. References are modelled as `<Type>Relationship` objects, so the entity graph is machine-derivable.
- **Retry safety**: no `Idempotency-Key`. Use `If-None-Match: *` on creates and `If-Match: <ModTime>` on updates; a conflict returns 412 Precondition Failed.
- **Async**: `Prefer: respond-async` (RFC 7240) returns 202. Long-running work is otherwise modelled as pollable resources (`workflow.WorkflowInfo`, `bulk.Request`).
- **Errors**: `{code, messageId, message}` on `application/json`. `code` is an 11-value closed enum. Every error response carries an `x-starship-traceid` header.
- **Rate limits**: none published. No `429` and no `Retry-After` anywhere in the contract.
- **Exports**: 2,398 list operations also serve `text/csv` and XLSX.
